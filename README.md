# SmaC

散布図を描いて、最小二乗の当てはめやスプライン補間をする Mac のアプリです。
データファイルを開くとすぐにグラフになり、軸・目盛り・文字・矢印などを右側の欄で直しながら、論文や報告書に使う図を作れます。

## できること

- **データを開く**: CSV・TXT・DAT など、数が並んだ文字のファイル(UTF-8・Shift_JIS)。見出しやコメントの行は飛ばします。窓に落としても開けます。
- **グラフ**: 線形・対数・逆数の軸、上と右の軸、目盛りと数字、方眼。1 つの書類に何枚でもグラフを置けます。
- **当てはめ**: 多項式・指数関数・対数関数・べき関数・一般の関数(パラメータ a〜g)の最小二乗、3 次スプラインとパラメトリックスプライン、ガウス関数・ローレンツ関数によるピークの当てはめ、最大値・最小値・ピークを探す、なめらかにする。
- **関数を描く**: `sin(x)`、`a*exp(-x/b)` のような式をそのまま曲線にします。
- **値を読む**: グラフの点にポインタを近づけると値が出ます。← → で隣の点へ動きます。
- **文字・図形**: 軸の題、凡例、矢印・線・枠・点・画像。上付き・下付き・ギリシャ文字の書式が使えます。
- **書き出す**: PDF・PNG、クリップボードへの図のコピー、変換したあとの値のテキスト。
- グラフは **SMP 形式**(.SMP)で保存します。データも一緒に入れておけば、データファイルがなくても開けます。

`Examples/` に試しに開けるデータがあります。

## 動く環境

macOS 14 以降(Apple シリコン・Intel)

## 入れ方

[Releases](https://github.com/yushun0825/smac/releases/latest) から `SmaC-<版>.dmg` をダウンロードして開き、`SmaC` を「Applications」(アプリケーション)フォルダへドラッグします。

## ソースから作る

[Xcode](https://developer.apple.com/xcode/) と [XcodeGen](https://github.com/yonaskolb/XcodeGen) が要ります。

```bash
brew install xcodegen
xcodegen generate
open SmaC.xcodeproj
```

`Tools/install.sh` で Release を作って `/Applications/SmaC.app` に入れます。
配る DMG は `Tools/release.sh` で作ります(Developer ID の証明書と、Xcode にサインインした Apple アカウントが要ります)。
データの読み書きと計算は `Packages/SMPKit`(Swift Package)にあり、`swift test` で確かめられます。

## 使い方の要点

| したいこと | やり方 |
| --- | --- |
| データを加える | ツールバーの「データを追加」、またはファイルを窓に落とす |
| 軸・データの見た目を変える | 左のサイドバーで選び、右のインスペクタで変える |
| グラフを動かす・大きさを変える | グラフの中をドラッグ / 角や辺をドラッグ |
| 軸の範囲を絞る | ツールバーの「範囲を囲む」で囲む。「範囲を合わせる」で元に戻す |
| 当てはめる | ツールバーの「解析」から選ぶ。結果はインスペクタの「曲線」に出る |
| 取り消す | ⌘Z(ほとんどの操作を取り消せます) |

くわしくはアプリの「ヘルプ」→「SmaC ヘルプ」を見てください。
